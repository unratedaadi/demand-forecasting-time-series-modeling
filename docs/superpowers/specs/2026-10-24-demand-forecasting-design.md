# Demand Forecasting Project Design

## Intent

Create a self-contained, portfolio-ready demand-forecasting project that runs without accounts, downloads, or non-standard Python packages. It demonstrates a retail planning workflow using deterministic synthetic daily demand data.

## Goals

- Generate realistic daily demand with trend, weekly seasonality, monthly effects, promotions, and noise.
- Compare a seasonal-naive benchmark against a trend-and-seasonality linear model.
- Export evaluation metrics, a 30-day forecast, visual assets, and an executive HTML dashboard.
- Make the workflow reproducible with one command.

## Non-goals

- Live data connections, model deployment, and claims based on private business data.
- Deep-learning forecasting; the project prioritizes an interpretable, dependency-free baseline.

## Approach

Use only Python's standard library: `csv` for data artifacts, `statistics` and small matrix routines for fitting, and inline SVG/HTML for visualization. The model predicts demand from an intercept, linear time trend, weekday indicators, and month indicators; the benchmark repeats demand from seven days ago. The report selects the lower-MAE model and makes the simulated-data assumption explicit.

## Constraints

- Synthetic data must be labeled as simulated.
- Randomness must be seeded for reproducibility.
- All outputs must be generated by `python3 run_pipeline.py`.
