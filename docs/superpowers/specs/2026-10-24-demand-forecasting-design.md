# Demand Forecasting Project Design

## Intent

Create a self-contained, portfolio-ready demand-forecasting project using real, public UCI retail data and no non-standard Python packages.

## Goals

- Aggregate weekly purchased quantities from UCI's real product-level sales data.
- Compare a seasonal-naive benchmark against a trend-and-seasonality linear model.
- Export evaluation metrics, an 8-week forecast, visual assets, and an executive HTML dashboard.
- Make the workflow reproducible with one command.

## Non-goals

- Live data connections, model deployment, and claims based on private business data.
- Deep-learning forecasting; the project prioritizes an interpretable, dependency-free baseline.

## Approach

Use only Python's standard library: `csv` for data artifacts, `statistics` and small matrix routines for fitting, and inline SVG/HTML for visualization. The model predicts weekly demand from an intercept and time/calendar features; the benchmark repeats the most recent four-week pattern. The report selects the lower-MAE model and makes the source-period limitation explicit.

## Constraints

- Use UCI Sales Transactions Weekly with attribution and a reproducible downloader.
- All outputs must be generated by `python3 run_pipeline.py`.
